Scan a page, land on the second

You read the paper copy on the train and want the audiobook to carry on from there. Point the camera at the page: the text is read on the device, matched against a transcript of the audio, and one second comes back. You confirm it, then the player seeks there. Nothing jumps on its own — a wrong guess that moves the book is worse than a guess you can refuse.

One skeleton, in every state. The book line, the frame and one button stand in exactly the same place and at exactly the same size from the first tap to the last; only what is inside them changes. The frame keeps its four brackets and its box whether it holds the camera, the frozen page, the result, or the book list. The button is the state machine — shutter, then spinner, then "Jump here" — so nothing has to appear or disappear to say what is happening.

Everything below is live. The first phone starts at the shutter and walks the whole loop — its shots alternate between a hit and a miss, so both endings are reachable — and the others open straight into the state they are named for. Tap the book title on any of them and the frame becomes the selector. Turn the guides on in the bar: the line, the frame and the button all land on the same two rails as every other screen, and the button sits on the centre of the gap between the frame and the tab bar.

The one screen, in every state

Idle

The viewfinder is a dark box with a bracket frame, not a photograph: a rendered page would promise a fidelity nothing here has. The hint sits over the camera on a slight darkening, where the eye already is, and leaves for good once a scan has been taken — it has said everything it can say. The line above names the book being matched, because a scan that silently searched the wrong book would explain none of its failures.

Reading

The frame freezes and dims, and the button itself becomes the loading state — same size, same place, so nothing on the screen moves. There is no progress arc claiming a number: OCR and a fuzzy match have no honest fraction, so the arc simply turns. A line of text saying "reading…" would be a second thing to look at for something the button already says.

Match

The result lands where the page was, inside the frame's own box: the snippet quoted back first, then the second and the chapter. Three lines of the book's own words say more about whether the match is right than any confidence score would. The button becomes the confirm. Refusing is the close at the top right — it goes back to the viewfinder, not to an apology, and it is far away from the thing that moves the book.

Choosing the book

The title in the line is a value with a caret — the same grammar as the library's filter, not a second pattern for the same act. Tapping it turns the frame's box into the list, so the selector costs no new surface. Each row says whether that book is already transcribed, as plain quiet text, because picking a book that cannot be scanned is the one mistake this list exists to prevent. The button waits, disabled, until a book is picked.

No match

A plain sentence, then what to do about it. The failure is named inside this book, because that is what actually happened: the text was read fine and found nowhere. A page of dialogue or a chapter heading gives the matcher almost nothing to work with, so the second line asks for more words rather than blaming the camera.

Not prepared

Scanning is worthless without a transcript, so the book that has none says so before the shutter, not after it: the frame carries the reason and the button carries the one thing to do about it. Preparing every book on import would burn an hour of battery for a feature most books never get pointed at.

Preparing

This is the one state that earns a number. Transcription walks the audio start to end and genuinely knows how far it got, so the button's arc is the fraction and the number stands in the middle of it. The same footprint as the shutter, doing the honest version of the same job. It runs behind playback, which the frame says out loud so nobody sits and watches it.
