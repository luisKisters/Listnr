Scope delivered

  • iOS app (Swift 6, SwiftUI, iOS 17+, XcodeGen project) implementing the locked mockups: four tabs, Library variant A, Player variant A with scrimmed cover and native wheel chapter picker.
  • AVFoundation player engine behind a protocol (deterministic mock for tests/previews), background audio session, lock-screen now-playing + remote commands, speed cycling, sleep timer that really stops playback.
  • Timestamped notes with auto-pause/resume and jump-to-timestamp list inside the note sheet.
  • SwiftData persistence with deterministic in-memory mode (-uitest) and fixed sample library seeded from committed fixtures (generated sine-wave audiobooks).
  • Verification infrastructure: scripts/test.sh dev|full, scripts/verify.sh (grep gates incl. accessibility-label gate, swiftlint, build, unit suite), evidence screenshots.
