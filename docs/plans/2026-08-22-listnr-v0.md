# Plan — Listnr V0, one-night build (2026-08-22)

Workflow per the Agentic Coding Playbook: plan (this file) → execution with tests written
alongside → review → fix → end-to-end. Only ox-alpha works on this; no other models.
Stop points are marked. If a stop point fails twice, park it in `ideas.md` with the reason and
move on — the app must stand in the morning.

## Goal

A running, end-to-end tested iOS app that implements the locked mockups 1:1:
four tabs, Library variant A, Player variant A (darkened cover, wheel chapters),
under-construction Reader/Scan, timestamped notes with auto-pause/resume,
background audio + lock-screen controls.

Out of scope tonight: real EPUB parsing, OCR scan, pairing UI, TestFlight upload automation
(documented instead), CloudKit.

## Phase A · Fixtures + scaffold

1. `scripts/make-fixtures.sh`: generate three short audio books (m4b with chapters via
   AVFoundation-compatible tooling: afconvert sine waves; chapters synthesized in-app when the
   container has none). Commit fixtures under `Fixtures/`.
2. `project.yml` → `xcodegen generate`. Targets: **Listnr** (app), **ListnrTests** (unit, hosted),
   **ListnrUITests** (UI). Bundle id `com.luisKisters.Listnr`, deployment target iOS 17.0,
   generator: XcodeGen.
   Validation: `xcodebuild build -scheme Listnr -destination 'platform=iOS Simulator,name=iPhone 17 Pro'`
   ends with BUILD SUCCEEDED.

## Phase B · ListnrKit (logic, no UI)

- `Book`, `Chapter`, `Note` models (SwiftData records + plain value types).
- `LibraryFilter` pure functions: filter/sort/search identical semantics to mockup app.js.
- Chapter math: chapter index from position, chapter boundaries, prev/next rules
  (prev within first 4 s restarts chapter, else jumps to chapter start).
- `PlayerEngine` protocol; `AudioPlayerEngine` (AVFoundation): play/pause, seek, speed,
  sleep timer, chapter skip, position observation, now-playing payload builder,
  remote command handling. Deterministic `MockEngine` for previews/tests.
- Note capture policy: save → pause before, resume after if it was playing.
- Tests per acceptance criterion, written as the code lands (not after).

## Phase C · Views (mockups 1:1)

- `RootView` TabView with four tabs; Reader/Scan = `UnderConstructionView` with the mockup's wording.
- Library screen per LOCKED.md variant A incl. spacing rule.
- Player screen per LOCKED.md variant A incl. scrimmed cover and wheel chapter picker.
- Note sheet: text editor + save; notes list per book; tapping a note seeks.
- Design tokens in one `Theme.swift`; no ad-hoc colors/sizes in views.

## Phase D · Verification

1. `scripts/test.sh dev` green (unit suite).
2. `scripts/test.sh full` green (unit + XCUITest golden paths: tabs exist, library filters,
   row → player, play/pause toggles, wheel chapter select changes scrubber, note sheet round-trip).
3. `scripts/verify.sh` green (grep gates: no emoji in Swift, accessibility labels on controls,
   no `print(` outside engine debug, no TODO without ticket comment; swiftlint; build; unit tests).

## Phase E · Review → Fix

Self-review against the standing reviewer brief: remove verbose code, unnecessary tests and
non-requested features; re-run every validation command; produce `docs/review-2026-08-22.html`.

## Phase F · End-to-end evidence

Boot iPhone 17 Pro, install, launch; screenshots of Library, Player playing, wheel sheet,
note flow, Reader/Scan construction screens (`scripts/evidence.sh`). Assemble PR body from them.

## Phase G · Ship

Push branch `listnr-v0`, open **draft** PR to main with evidence. Human approves merge.

## Phase H · Device/TestFlight path

certificate + App Store Connect API key exist, attempt an upload via `altool`; otherwise write
exact manual steps into `docs/testflight.md`. Never modify keychain or certificates beyond reads.
